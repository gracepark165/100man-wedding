# 100만원으로 결혼하기

시기, 지역, 하객 수, 장소, 식사 방식을 버튼으로 고르면 총 100만원(식대 포함, 신혼여행 제외) 안에서
항목별 예산, 장소 안내, 준비 일정을 보여주는 웹 프로토타입입니다.
직접 그린 오리 커플이 연못 그림의 갈색 다리에서 낚시하며 안내하고, 예비비가 넉넉할수록 물고기를 잘 잡습니다.

- 배포 파일: `index.html` (파일 하나로 동작, 외부 서버 없음)
- 소스: `src/app.src.html`, 그림: `src/*.webp`
- 다시 만들기: `python3 src/build.py`

금액 단가는 프로토타입용 예시 값이며 실제 견적이 아닙니다.

## 운영자 안내

### 공공예식장 목록 고치기 (`src/venues.json`)

항목 하나가 시설 하나입니다.

| 필드 | 뜻 | 예 |
|---|---|---|
| `id` | 영문 고유 이름 | `hannam-garden` |
| `name`, `gu` | 시설 이름, 자치구 | `남산 한남 웨딩가든`, `용산구` |
| `area` | 세부 지역 코드. `gn` 강남·서초·송파, `mp` 마포·용산·종로, `gs` 강서·영등포·구로, `gb` 강북·노원·성북. 해당 없으면 `""` | `mp` |
| `cap` | [최소, 최대] 수용 인원 | `[80, 150]` |
| `fee`, `food`, `open` | 화면에 그대로 보이는 대관료, 음식 조건, 예약 조건 | `무료` |
| `url` | 공식 안내 페이지 | |
| `checked` | **직접 확인한 날짜**. 비어 있으면 화면에 보이지 않아요 | `2026-11-20` |

지금 들어 있는 10곳은 공식 사이트 검색 결과로 만든 초안이라 모두 `checked`가 비어 있습니다. 공식 페이지나 전화(1899-2154)로 수용 인원, 대관료, 음식 반입을 확인한 뒤 `확인 필요`를 고치고 날짜를 넣어 주세요. 화면의 "정보 기준일"은 가장 오래된 확인 날짜로 표시됩니다.

### 신청서와 방문 통계 켜기 (`src/config.json`)

```json
{"formUrl": "", "formSummaryEntry": "", "goatcounter": ""}
```

- `formUrl`: 구글폼 응답 주소(`https://docs.google.com/forms/d/e/.../viewform`). 폼에는 이름, 연락 방법, 개인정보 수집·이용 동의, 결과 요약(단답 또는 장문) 질문을 둡니다.
- `formSummaryEntry`: 구글폼 '미리 채워진 링크 받기'에서 결과 요약 칸의 `entry.숫자`.
- `goatcounter`: GoatCounter 사이트 코드(`코드.goatcounter.com`의 `코드`).
- 비어 있으면 신청 카드와 통계가 나타나지 않습니다.

값을 바꾼 뒤에는 `python3 src/build.py`로 `index.html`을 다시 만들고 커밋하세요.
