# 100만원으로 결혼하기

시기, 지역, 하객 수, 장소, 식사 방식을 버튼으로 고르면 총 100만원(식대 포함, 신혼여행 제외) 안에서
항목별 예산, 장소 안내, 준비 일정을 보여주는 웹 프로토타입입니다.
직접 그린 오리 커플이 연못 그림의 갈색 다리에서 낚시하며 안내하고, 예비비가 넉넉할수록 물고기를 잘 잡습니다.

- 배포 파일: `index.html` (파일 하나로 동작, 외부 서버 없음)
- 소스: `src/app.src.html`, 그림: `src/*.webp`
- 다시 만들기: `python3 src/build.py`

금액 단가는 프로토타입용 예시 값이며 실제 견적이 아닙니다.
